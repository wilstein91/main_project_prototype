# 그림 넣는 곳

여기에 파일을 넣으면 **코드를 고치지 않아도** 화면이 바뀐다.
파일이 없으면 SVG 로 그린 대체 화면이 그대로 보인다 (`src/lib/art.ts`).

확장자는 `webp` · `avif` · `jpg` · `png` 중 아무거나 되고,
**앞에 있는 것이 우선**이다 (용량이 작은 순).

| 파일 이름 | 권장 크기 | 쓰이는 곳 |
|---|---|---|
| `hero` | 1600×460 | 홈 상단 배너 · `/about` 머리 |
| `side-left` | 520×1400 | 화면 왼쪽 여백 (1400px 이상에서만 보인다) |
| `side-right` | 520×1400 | 화면 오른쪽 여백 |
| `header-arm` | 900×200, 배경 투명 | 헤더 가운데 장식 |
| `notfound` | 800×500 | 404 |
| `auth-signup` · `auth-login` · `auth-reset` | 800×500 | 인증 화면 머리 띠 |
| `empty` | 800×500 | 빈 목록 |
| `error` | 800×500 | 오류 화면 |
| `plate-teal-*` · `plate-bronze-*` | 표에 크기 명시 | 버튼 판 (9조각 분할) |

### 아직 안 쓰는 것 — 해당 기능 만들 때 붙인다

| 파일 이름 | 쓸 곳 | 언제 |
|---|---|---|
| `sec-stock` | 종목 페이지 머리 | Phase 3 |
| `sec-trending` | 화제 종목 머리 | Phase 3 |
| `sec-news` | 뉴스 섹션 머리 | Phase 4 |
| `sec-profile` | 프로필 머리 | Phase 2 |
| `search-empty` | 검색 결과 없음 | Phase 2 |
| `tier-1`~`tier-4` | 회원 등급 문장 (길손·식객·장수·호걸) | Phase 3 |

### ⚠️ 아직 없는 것

| 파일 이름 | 왜 필요한가 |
|---|---|
| `plate-teal-246x80` | `가입하고 글쓰기` 버튼에 딱 맞는 판. 시트에서 빠져 왔다. **지금은 `plate-teal-316x88` 을 9조각으로 늘려 쓰고 있어 화면은 정상이다** — 굳이 안 뽑아도 된다 |

> 버튼 판은 **9조각 분할**(`border-image`)로 늘려 쓰므로, 크기별로 다 갖출
> 필요가 없다. 청록 하나·갈색 하나면 모든 버튼을 덮는다. 나머지 판은
> 특정 크기에 딱 맞춰 쓰고 싶을 때를 위한 여분이다.

## 만들 때 지킬 것

- **글자를 넣지 않는다** (`no text`). 제목·메뉴 글자는 코드가 얹는다.
  그림 안에 글자가 있으면 화면 폭이 바뀔 때 같이 찌그러진다.
- `hero` 는 **왼쪽 1/3 을 어둡고 비워 둔다.** 그 위에 서비스명이 얹힌다.
- `side-left` · `side-right` 는 **본문 쪽(안쪽) 가장자리가 어둠으로 사라지게**
  한다. 경계선이 보이면 벽지처럼 보인다.
- 톤은 화면 바탕(`#171009` 따뜻한 먹색)과 이어지게. 너무 밝으면 글이 안 읽힌다.

## 넣은 뒤 확인

개발 서버를 켜 두었다면 새로고침만 하면 된다. 그림이 안 바뀌면 파일 이름과
확장자를 다시 본다 (대소문자 구분).
