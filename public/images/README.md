# 그림 넣는 곳

여기에 파일을 넣으면 **코드를 고치지 않아도** 화면이 바뀐다.
파일이 없으면 SVG 로 그린 대체 화면이 그대로 보인다 (`src/lib/art.ts`).

확장자는 `webp` · `avif` · `jpg` · `png` 중 아무거나 되고,
**앞에 있는 것이 우선**이다 (용량이 작은 순).

| 파일 이름 | 권장 크기 | 쓰이는 곳 |
|---|---|---|
| `hero` | 1600×460 | 홈 상단 배너 · `/about` 머리 |
| `side-left` | 520×1400 | 화면 왼쪽 여백 (1400px 이상에서만 보인다) |
| `side-right` | 520×1400 | 화면 오른쪽 여백 |
| `header-arm` | 900×200, 배경 투명 | 헤더 가운데 장식 |
| `notfound` | 800×500 | 404 |

## 만들 때 지킬 것

- **글자를 넣지 않는다** (`no text`). 제목·메뉴 글자는 코드가 얹는다.
  그림 안에 글자가 있으면 화면 폭이 바뀔 때 같이 찌그러진다.
- `hero` 는 **왼쪽 1/3 을 어둡고 비워 둔다.** 그 위에 서비스명이 얹힌다.
- `side-left` · `side-right` 는 **본문 쪽(안쪽) 가장자리가 어둠으로 사라지게**
  한다. 경계선이 보이면 벽지처럼 보인다.
- 톤은 화면 바탕(`#171009` 따뜻한 먹색)과 이어지게. 너무 밝으면 글이 안 읽힌다.

## 넣은 뒤 확인

개발 서버를 켜 두었다면 새로고침만 하면 된다. 그림이 안 바뀌면 파일 이름과
확장자를 다시 본다 (대소문자 구분).
